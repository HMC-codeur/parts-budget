# Parts

Budget personnel, en français ou en hébreu. Chaque revenu se répartit entre des enveloppes (Loisirs / פנאי, Imprévus / בלתי צפוי, Épargne / חיסכון, ou les tiennes). Les dépenses viennent ensuite se soustraire au solde. La monnaie est le shekel (₪). Le choix de langue (FR / עב) reste dans le navigateur.

Les données restent dans le navigateur (`localStorage`). Aucun compte.

## Lancer

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000). Sur téléphone, ajoute l’app à l’écran d’accueil depuis le navigateur une fois le site servi en HTTPS : le manifeste et le service worker la rendent installable.

```bash
npm test
npm run lint
npm run build
```
